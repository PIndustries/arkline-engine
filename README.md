# Arkline

A shared space sandbox built in Rust by P.Industries and contributors. Fly ships,
mine finite resources, operate drones, and trade in a persistent universe where
the server controls the world state.

**Early-access source · 26.10.11.6.** Arkline is under active development, with
unfinished systems and visual rough edges. Source can be ahead of deployed clients;
[Releases](https://github.com/PIndustries/arkline-engine/releases) identifies downloadable builds.

[Website](https://arkline.network) · [Play in your browser](https://play.arkline.network) ·
[Downloads](https://github.com/PIndustries/arkline-engine/releases) ·
[Official Wiki](https://github.com/PIndustries/arkline-engine/wiki)

## One community, room to explore

P.Industries focuses on the official Arkline network: operating the infrastructure
and developing a shared universe with the community. Open source gives players
and contributors a direct way to inspect the engine, improve its security and
balance, and shape how it plays.

You are welcome to host your own world, run local experiments, or build a fork.
We hope useful ideas return as issues and pull requests that strengthen the shared
ecosystem. Independent networks and different perspectives are welcome too.
See the [community direction](https://github.com/PIndustries/arkline-engine/wiki/Community-and-Roadmap).

## Start here

Desktop and browser clients offer the official Production world, a separate Test
world, and custom servers. Production and Test have separate pilots and economies.
For a local universe, run `arkline-client --local`.

The [player and developer guide](https://github.com/PIndustries/arkline-engine/wiki/Player-Guide)
contains installation, platform requirements, source builds, first flight and
validation commands. Current models are generated in Rust; GLB import is planned
but is not implemented yet.
