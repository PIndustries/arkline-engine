# Independent-bay fixture checks

These source-bound scripts reproduce the v12 stationary fixture review. They
currently run from the enclosing evidence workspace, with inputs in
`pioneer-independent-bays-20261026/` and the integration checkout named
`arkline-independent-bay-hull/`. The private candidate archive retains those
inputs and paths. No script grants world or travel admission.

`candidate_routes.py` is the shared geometry-only phase generator. The provider
fixture, actual-body checker and own/peer hardware checks use the same poses.
`check_motion.py` includes loaded clamp-closed strokes and reversed continuous
swept domains; a reverse-domain proof is not a cancellation policy implementation.
`check_peer_domains.py` covers independently progressing lane machinery and drone
unions. Contact rays are sampled geometry evidence, not forces or strength.

The body checker uses actual cached class triangle export and a conservative
Mining-head articulation bound. Its enclosed-oblique-solid negative control
ensures containment is checked even when triangle AABBs overlap without a surface
intersection. Ten-micrometre inward tolerance permits intended tangent contact;
there is no arbitrary own-hull or socket collision exemption.
