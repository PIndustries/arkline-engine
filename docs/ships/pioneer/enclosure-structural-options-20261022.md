## A: retain the bay and design a broad bridge

Keep the existing bay, chair, offset portal and boarding connection. Build a coherent low pilot station around Z 3 using integrated housings, recessed instruments and a deliberate peripheral structure. Preserve the open forward sightline and port-side circulation.

This can improve construction depth and instrument integration without pretending to match the concept's centered rear aisle. It requires a revised broad-bridge design reference for honest visual acceptance. Existing solid envelopes can contain replacement skins without a room migration; any real mount or collision changes still need validation against the latest copied avatar.

## B: study a deeper pilot pod within the sampled hull envelope

Proposed envelope: **X 27.8–34.9, Z 0.8–5.2**, with the same floor and ceiling: **7.1 × 4.4 × 3.2 m**. Keep the current chair and eye.

A proposed 1.4 m clear branch at X 26.4–27.8 / Z 0–3.7 would join a centered rear aperture at X 27.8 / Z 3. The original Z 0 connector and X 31.6 / Z 0 portal would remain parallel boarding access. Preserve the port boarding foyer and all hatch/lift anchors. A proposed 2 m side connection at X 31.8–33.8 / Z 0.8 would retain the chair dogleg. This extra side access is a disclosed adaptation to the concept.

Required work, before committing the structure:

- Check the complete original source triangles and machinery/structure clearance; sampled rays are insufficient.
- Remove the old rear bulkhead only where it crosses the proposed pod, retaining the existing connector and foyer boundaries.
- Add real extension floor, roof, walls, supports, cells and portal definitions shared across views.
- Validate current capsules, supports, seat transitions, boarding routes and actuator states on a fresh coherent world copy.
- Make an explicit versioned geometry-admission decision. Room-layout SHA does not cover the physical enclosure; no general registration upgrade exists. Preserve exact avatar, jobs, cargo and ledgers. Reject an incompatible candidate rather than relocate or reset.
- Treat the rear aperture as open unless a real door actuator, collision sweep and authoritative state are implemented.

Neither option consumes room cores ending at X 20. Neither authorizes enlarging the exterior or changing room roles.
