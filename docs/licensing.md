## Selected license

The owner selected GNU Affero General Public License version 3 only
(`AGPL-3.0-only`). The unmodified license text is in [LICENSE](../LICENSE). This choice covers
first-party repository code and original assets unless an individual file states
otherwise. All five Rust workspace packages inherit the same license metadata.
Third-party dependencies and embedded third-party assets retain their own terms.
Branding permissions are described separately in [TRADEMARKS.md](../TRADEMARKS.md).

The repository remains private pending explicit owner approval to publish. This
operational publication decision is separate from the copyright permissions
already granted to recipients under the license; it does not add restrictions to
AGPL. Existing release artifacts are not silently rebuilt or relabeled by this
source change; record the source revision and licensing of each future release.

## Distribution and hosting

Recipients may use, modify and redistribute the covered software, including for
commercial purposes, subject to the license. Distribution of covered binaries
must satisfy the corresponding-source and notice requirements. Follow the full
license rather than treating this summary as a substitute.

Section 13 requires modified network-interactive versions to prominently offer
users interacting with them over a network an opportunity to obtain the
Corresponding Source of that version. Before operating such a release, provide a
visible source offer and the matching source/build material; a link to an unrelated
or newer upstream version is not a substitute. Private credentials, player saves
and production databases do not belong in the source release.

Independent operators need not join the official network or submit changes
upstream. Contributions to the official project still go through review; a license
does not grant official-server access, deployment rights or maintainer status.

## Dependency and asset review

The locked metadata inventory at ebfa4c9 contained 456 resolved external packages
across all platform targets, all with declared license expressions. The declared
expressions include permissive alternatives and separate bundled-font terms.
Metadata alone is not a completed compatibility/provenance or attribution review.
Before public source/binary distribution, review actual license files, select
appropriate alternatives, collect required notices, and confirm original asset
rights. Keep this gate in [public-preview-readiness.md](public-preview-readiness.md) until recorded complete.
